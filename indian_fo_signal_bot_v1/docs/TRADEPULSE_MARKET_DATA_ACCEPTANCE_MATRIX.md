# TradePulse AI - Phase 4 market-data acceptance matrix

Scope: source inspection and deterministic **offline simulation**. Provider-shaped responses replace only urllib transport in `test_phase4_market_data.py`; they are not broker observations. No live broker request, account/profile request, instrument-master download, receipt issuance, production scan, scheduler start or Telegram delivery is authorized by this report.

`PASS` means the specified offline behavior is implemented and demonstrated by passing tests. `FAIL` means a reproducible current defect. `NOT_TESTED` means no matching external acceptance evidence. `BLOCKED` means a required capability or independently established prerequisite is absent. Offline PASS never changes the live result.

The final integrated counts, commands and process exits belong to [TRADEPULSE_PHASE4_ENGINEERING_REPORT.md](TRADEPULSE_PHASE4_ENGINEERING_REPORT.md). The previous reported Upstox HTTP 403 is historical user evidence; its provider/account cause remains unknown. Angel One has no verified live result. The selected broker is never changed or silently failed over.

## Reproduction and next authorized step

Run offline contract/provider tests from the project directory:

```powershell
python -B -W error::ResourceWarning -m unittest test_phase4_market_data test_market_data_contract test_angel_market_data -v
```

Configuration preflights are offline and do not change the selected broker:

```powershell
python -B .\upstox_diagnostics.py --symbol RELIANCE --check-config --json
python -B .\diagnostics.py --market-data-only --symbol RELIANCE --check-config --json
```

An unselected provider should be BLOCKED; do not edit selection or credentials to obtain a PASS. The actual preflight result is recorded in the engineering report.

After separate authorization, use **one** diagnostic for the explicitly selected provider during its configured NSE session with completed five-minute candles available. For the currently reported selected Upstox provider:

```powershell
python -B .\upstox_diagnostics.py --symbol RELIANCE --json
$LASTEXITCODE
```

This command contacts the existing quote endpoint and, only after an eligible quote, the intraday-candle endpoint. It does not call profile, funds, holdings, positions or trading endpoints. Stop after a rejection and review the sanitized status/code/message and exit code. No automatic retry loop or provider switch is part of this procedure. A successful result accepts only the tested RELIANCE cash-data path and cannot authorize F&O, historical replay or Strategy 3.
